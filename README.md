# PopX

A modern React-based web application built with Vite, Tailwind CSS, and React Router. This project supports hot reloading, linting, and has a clean and minimal setup to kickstart your frontend development.


## 📁 Project Structure

```bash
popx/
├── public/           # Static assets
├── src/              # Application source code
│   ├── assets/       # Images and static files
│   ├── components/   # Reusable components
│   ├── pages/        # Page components
│   ├── providers/    # Context providers (e.g., AuthProvider)
│   ├── routes/       # Route definitions
│   ├── App.jsx       # Main app component
│   └── main.jsx      # Entry point
├── index.html        # HTML template
├── tailwind.config.js
├── package.json
└── vite.config.js
```

## 🛠️ Tech Stack

| Category       | Technologies                          |
|----------------|---------------------------------------|
| Core           | React 19, React DOM, React Router 7                   |
| Styling        | Tailwind CSS 4                 |
| Build Tool     | Vite                                  |
| Code Quality   | ESLint, React Hooks                   |
| Icons          | React Icons                           |
| Notification style          | React Hot Toast                           |

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm (v9 or higher)

## Installation
```bash
git clone https://github.com/aburayhan-bpi/popX-educase-india
cd try-now-landing-page
npm install
npm run dev
```
